Membros Busters

União

Como o metal afia o metal, assim também nós melhoramos uns aos outros.

Transparência

É de suma importância a total transparência entre todos os processos do projeto para com nossos clientes.

Respeito

Como busters, o respeito para com um é respeito para com todos; da mesma forma, o desrespeito para com um é também desrespeito para com todos.

MySQl - Workbench

Banco de dados o qual é responsável por guardar/armazenar os dados (de forma segura e organizada) provenientes do cadastro, bem como das capturas vindas do sensor MQ-2 e dos dados fornecidos por nossos clientes.

Sensor MQ-2

O sensor MQ-2 é responsável pela precisa captura de gás inflamável presente nalguma área, de forma imediata e segura.

API

A APi, responsável por ligar as operações inteternas do sistema, gera integridade ao cliente ao dispor, de forma dinâmica e em tempo real, uma visualização de dados capturados pelo sensor MQ-2 numa interface gráfica (dashboard), a efeito de nossos clientes poderem efetuar um pleno gerenciamento e controle da situação em questão.
